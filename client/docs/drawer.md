# Vehicle Drawer

## Global drawer

`VehicleDrawer` is rendered once at app level and controlled through context.

- Anchor: right
- Width: `380px`
- Sections:
  1. Position
  2. Engine
  3. Fuel & Mileage
  4. Power
  5. Network
  6. Vehicle State

## Header

- Vehicle ident
- Status chip
- VIN
- Last update timestamp

## Open/close triggers

- Opens from map marker click
- Opens from vehicle/history row click
- Closes from drawer close button or backdrop click
